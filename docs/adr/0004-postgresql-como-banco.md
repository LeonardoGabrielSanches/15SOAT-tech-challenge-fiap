# PostgreSQL como banco de dados

O domínio é fortemente relacional: Cliente → Veículo → OS → itens → Serviço e Peça/insumo. As regras de consistência dependem de transações ACID que envolvem mais de um agregado (ADR 0003). Por isso descartamos bancos não relacionais e escolhemos o PostgreSQL. Ele é open source, sob a licença PostgreSQL, sem custo de uso. Oferece transações ACID, tipo `numeric` para dinheiro e quantidades fracionadas, sequências para o número da OS e um provedor maduro para .NET (Npgsql/EF Core). Também roda com uma imagem oficial no `docker-compose.yml`. As regras de negócio vivem no domínio. Restrições do banco, como placa única ou índice único parcial para uma OS em andamento por veículo, são apenas uma segunda barreira contra concorrência, nunca o único lugar onde a regra existe.
